# rush — бои 500 на 500 и нейросеть, которая в них сражается

*[English version](README.md)*

**rush** — двумерный командный шутер с видом сверху для очень больших сражений: две армии до 500 бойцов бьются за
~100 контрольных точек на карте 21 000 × 13 000 px. Бойцы восьми классов (танк, снайпер, разведчик, …) различаются
скоростью, дальностью, скорострельностью, здоровьем и магазином; патроны пополняются только на своей неоспариваемой
точке; погибшие возрождаются на точках своей стороны. Весь мир — пакетная симуляция на PyTorch и считается на GPU.

В репозитории — мир игры, командир армии, обученная **нейросеть-боец**
([koskokos/rush-soldier](https://huggingface.co/koskokos/rush-soldier) на Hugging Face), самообучение поколениями,
инструмент, который проводит и записывает бой, и просмотрщик записей в браузере.

## 1. Сгенерировать бой

```bash
pip install -e .                       # Python ≥ 3.10, PyTorch ≥ 2.1
rush-battle --blue hf:koskokos/rush-soldier --red random --map Front50 --out battle.arena.bin.gz
```

`Front50` — карта 50 на 50: бой идёт минуты даже на процессоре. Главная карта — `Warfront500` (500 на 500,
~7 000 решений за бой, около часа на одной видеокарте):

```bash
rush-battle --blue hf:koskokos/rush-soldier --red hf:koskokos/rush-soldier --map Warfront500 --device cuda --out warfront.arena.bin.gz
```

Игроки: `hf:<репо>[/<вариант>]` (сеть с Hugging Face), `net:<папка>` (локальные `config.json` + `model.safetensors`
или папка чекпоинта обучения), `random` (необученная сеть); `#Имя` задаёт подпись в просмотрщике. Карты:
`Warfront500`, `Front150`, `Crossing150`, `Front50` или сгенерированная — `steppe:11`, `urban:12`, `forest:13`,
`delta:14`, `plateau:15` (`<тема>:<seed>[:<размер команды>]`). `--max-decisions N` останавливает бой раньше.

Из Python:

```python
from rush.battle import play
result = play("hf:koskokos/rush-soldier", "random", map_name="Front50", out="battle.arena.bin.gz")
print(result["score"], result["winner"])
```

## 2. Посмотреть запись

```bash
rush-view battle.arena.bin.gz          # или: rush-battle ... --view
```

Просмотрщик откроется в браузере. Масштаб — колесом, двумя пальцами или кнопками ±; «Режиссёр» следит за самой
жаркой схваткой; «Классы» — легенда классов.

## 3. Дообучить самому: самообучение поколениями

```bash
# старт с опубликованного бойца; поколение 0 = эта сеть, она же «якорь»
rush-selfplay --init hf:koskokos/rush-soldier --run-dir runs/sp --device cuda \
    --maps Front150 --worlds 4 --rollout 500 --gen-every 5
```

Каждая итерация — `--rollout` решений в `--worlds` параллельных боях: обучаемая сеть на одной стороне, замороженное
поколение (последнее, иногда более старое) на другой, стороны меняются после каждого боя; затем шаг PPO по исходу
(урон, убийства, захваты, очки, победа). Каждые `--gen-every` итераций в `runs/sp/league/cand_XXXXX/` появляется
кандидат. Во втором терминале проверьте его:

```bash
rush-gate --run-dir runs/sp --map Front150 --device cuda      # пары боёв со сменой сторон + парный t-тест
```

Если кандидат значимо сильнее, он становится новым поколением (`league/gen_XXX`, `league/current.json`), и
работающий тренер начинает сражаться с ним. Метрики — в `runs/sp/models15/metrics.jsonl`; продолжить —
`rush-selfplay --run-dir runs/sp --resume`. Настройки по умолчанию (шесть миров 500 на 500, 1000 решений) требуют
большой видеокарты и ~35 ГБ ОЗУ; `Front150` с 4 мирами помещается на одну обычную. Посмотреть любого кандидата:

```bash
rush-battle --blue "net:runs/sp/league/cand_00005#Кандидат" --red "net:runs/sp/league/gen_000#Поколение 0" --map Front150 --view
```

## Нейросеть-боец

Одна сеть управляет каждым бойцом армии, всеми 8 классами (класс — часть её наблюдения). На каждого бойца и решение:
трансформер по токенам сущностей (ближайшие свои и враги, пули, точки, последние замеченные враги, сетки стен), LSTM
и внимание с запросом из состояния по дополнительным токенам (до 56 бойцов, 32 самые опасные пули, грубая карта боя
17 × 17). Действия: 9 ходов, выстрел, 7 поворотов, рывок.

Армией командует `rush/army_commander.py`: какую точку брать каждому отряду из 8 бойцов, кому идти на пополнение, где
возрождаться погибшим. Сеть видит свой приказ и воюет; она боец, а не командир.
